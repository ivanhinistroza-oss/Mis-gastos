# Mis gastos

App web para llevar en orden lo que gastas con Yape, Plin y tarjetas. Lee los avisos del celular y los correos del banco, sugiere categorías y muestra un resumen del mes con presupuesto.

- Usarla: https://ivanhinistroza-oss.github.io/Mis-gastos/
- Instalarla y configurar los celulares: [INSTRUCCIONES.md](INSTRUCCIONES.md)

Todo está en `index.html` (HTML, CSS y JavaScript, sin librerías). Los datos van a Firebase (proyecto `mis-gastos-64b90`); las reglas de seguridad están en `firestore.rules`.
